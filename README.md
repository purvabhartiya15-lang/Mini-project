# Campus Parking Management System

## About the Project
The Campus Parking Management System is a C++ project designed to manage vehicle parking on a college campus. It helps allocate parking slots, track parked vehicles, and prevent duplicate vehicle entries.

## Features
- Park a vehicle in an available slot.
- Remove a vehicle when it exits.
- Search for a vehicle using its registration number.
- Display occupied and available parking slots.
- Prevent duplicate vehicle entries.
- Manage a waiting queue when all parking slots are occupied.

## Technologies Used
- C++
- Data Structures
- Git and GitHub

## Data Structures
- Array for parking slots.
- Queue for waiting vehicles.
- Stack for available parking slots.
- Unordered set for duplicate detection.

## How to Run
1. Download or clone this repository.
2. Open the project in VS Code.
3. Compile the C++ file using a C++ compiler:

   `g++ vehicle.cpp -o vehicle`

4. Run the program:

   `./vehicle`

   On Windows, use `.\vehicle.exe` in PowerShell or Command Prompt.

## Purpose
This project demonstrates the use of data structures to manage parking slots efficiently and prevent duplicate vehicle entries.
